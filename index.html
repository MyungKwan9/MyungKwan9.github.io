Featured Project

VAN Operations KPI Dashboard

VAN Operations KPI Dashboard는 전문 개발자 포트폴리오가 아니라, 현업 운영 경험을 KPI와 화면 구조로 정리한 실무형 MVP입니다. 거래, 정산, 보류정산, 운영비용, 사업장 이슈를 가상의 샘플 데이터로 구조화하고, 운영 담당자가 빠르게 현황을 이해할 수 있는 화면을 실험했습니다.

  • 실제 업무 데이터는 사용하지 않고 익명화 샘플 데이터만 사용
  • Store A~G 형태의 샘플 사업장 데이터 구성
  • 현업 문제를 KPI와 화면 구조로 바꾸는 실험형 포트폴리오
  • GitHub / Vercel 기반 배포 경험
